# Plateit API

Plateit is a pragmatic, REST-like API that handles the fulfilment of UK number plates ordered online. It powers the [Plateit admin area](https://admin.plateit.co.uk) and can be used to build your own applications, too.

> Read the [suggested integration guide](/fundamentals/suggested-integration.md) for a typical use case.
